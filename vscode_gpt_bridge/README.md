# Kaz GPT Bridge

## Cómo abrirlo

No lo ejecutes desde PowerShell escribiendo `Kaz GPT Bridge: Abrir chat`.

En VS Code haz lo siguiente:

1. Abre la paleta de comandos con Ctrl+Shift+P.
2. Escribe `Kaz GPT Bridge: Abrir chat`.
3. Selecciona el comando.

## Requisitos

- Tener VS Code abierto sobre esta carpeta.
- Conexión a internet para cargar Puter.
- Sesión activa en Puter desde el navegador.
